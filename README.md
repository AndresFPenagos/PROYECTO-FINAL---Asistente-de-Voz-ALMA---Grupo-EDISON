# PROYECTO-FINAL---Asistente-de-Voz-ALMA---Grupo-EDISON
Diseño de hardware de ALMA, un altavoz inteligente de mesa, ejecutado en Linux en una arquitectura ARM64.
ALMA integra interacción por voz, reproducción de música, pantalla
táctil a color e iluminación ambiental RGB. El producto debe conservar configuración ante desconexión
eléctrica y permitir control de otros dispositivos inteligentes como cliente IP en red local.
El alcance del proyecto abarca la especificación completa del diseño de hardware: esquemáticos
completos, PCBs 100% enrutadas, reglas de integridad de señal aplicadas y la entrega del paquete de
fabricación/ensamble y de la documentación técnica asociada. No se implementa firmware ni software,
pero el equipo debe definir cómo el software interactuaría con el hardware y presentar una arquitectura
lógica en capas
